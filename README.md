A program that writes one haiku (5-7-5, 72 characters) to `/output/entry.txt` about debugging: past midnight a log insists nothing is wrong, and the last line turns the poem — git blame names the debugger. `main.py` (Python 3.13, stdlib only, no network) checks the text against the gate (3 lines, 5-7-5 syllables, 1–200 characters) and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
